# MinStockNotify — уведомления о минимальном остатке (1С: Управление IT-отделом)

Раз в сутки проверяет остатки на местах хранения «!Коммутационная» и «!Основная серверная» (со всеми вложенными)
и присылает в Telegram-чат и/или на почту список номенклатуры, достигшей «Минимального остатка».

## Что внутри
- CommonModules/МинОстаткиУведомления — вся логика (расчёт, текст, постановка в очередь Telegram).
- ScheduledJobs/МинОстаткиУведомленияРегл — регламентное задание.

## Установка
1. Загрузить как новое расширение (не трогая SDPIntegration):
   1cv8.exe DESIGNER /F "<путь к базе>" /N "<логин>" /P "<пароль>" /LoadConfigFromFiles "<эта папка>" -Extension MinStockNotify /UpdateDBCfg
   (для серверной базы вместо /F — /S "сервер\база"). Сначала — на КОПИИ базы.
2. В модуле МинОстаткиУведомления, функция ПолучитьНастройки():
   - канал Telegram включается заполнением КодЧатаTelegram — код элемента справочника «Telegram пользователи» для общего чата
     (у групп идентификатор отрицательный, элемент при необходимости создать вручную);
   - канал почты включается заполнением ПочтаПолучатели (адреса через «;»), ПочтаУчетнаяЗапись — наименование
     учетной записи, пусто = системная;
   - при необходимости ИмяБота, список КорневыеМестаХранения, ПовторятьКаждыйДень.
3. Расписание: выполнить на сервере МинОстаткиУведомления.НастроитьРасписание() (08:00 ежедневно, время сервера 1С)
   либо задать вручную в «Регламентные и фоновые задания».
4. Убедиться, что включено штатное задание «Telegram отправка исходящих сообщений» и настроен прокси.

## Проверка без отправки
Сообщить(МинОстаткиУведомления.ТестовыйЗапуск()); — покажет текст и все позиции ниже минимума, ничего не отправляя и не запоминая.

## Логика
- Остаток = регистр накопления «Остатки» по местам хранения в иерархии корней; для карточки берётся владелец (номенклатура).
- Учитываются позиции с МинимальныйОстаток > 0. Условие срабатывания: остаток <= минимума.
- «В расчёт потребностей включать аналоги»: к остатку добавляется остаток остальной номенклатуры того же вида.
- Без напоминаний: позиция уведомляется один раз; после возврата выше минимума — снова может сработать.
- Если корневое место не найдено — расчёт прерывается и пишется ошибка в журнал регистрации (событие «МинОстаткиУведомления»).
> В публичной копии получатели почты в `ПолучитьНастройки()` очищены — заполните `ПочтаПолучатели` и/или `КодЧатаTelegram` под себя.
