# Рабочий процесс и грабли

## Цикл разработки без конфигуратора

1. Исходники расширения → `gen.py` (или правка XML) → каталог выгрузки.
2. Пакетный режим на **копии** базы: `/LoadConfigFromFiles <каталог> -Extension <Имя> /UpdateDBCfg`,
   `/CheckModules -Server -ExternalConnection -Extension <Имя>`, `/CheckConfig`.
3. Тестовая сборка с тестовым модулем вызывается по COM (`V83.COMConnector`, 32-разрядный PowerShell
   `SysWOW64\WindowsPowerShell`), результат — в текстовый файл.
4. Боевая сборка → `/DumpCfg …cfe` → установка в рабочую базу.

Скрипты — в [`tools/`](../tools). Каждый запуск — отдельный `.bat` с новым именем (так проще вести историю).

## Грабли BSL / запросов

- `И`, `Знач`, `Попробовать`, `В` — зарезервированные слова, переменными быть не могут.
- `ПОДОБНО` не работает с `ПРЕДСТАВЛЕНИЕ()` — использовать поле `.Наименование`.
- У измерения регистра сведений нельзя включать «Использовать в итогах».
- Условие виртуальной таблицы остатков — только простые отборы; `ИЛИ` внутри параметра лучше не использовать.
- В файле `.ps1` — UTF-8 с BOM; в тестовом `.bsl` — без двойного BOM.
- HTTP-сервис в расширении применяется только после перезапуска пула приложений (IIS) / новых сеансов.
