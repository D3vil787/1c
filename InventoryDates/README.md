# InventoryDates — отчёты по инвентаризациям

Расширение для «Управление IT-отделом 8» (подсистема «Номенклатура и склад»).

- **Инвентаризации по местам хранения** — дата последней инвентаризации каждого места (само место и самая старая
  дата среди вложенных), сортировки, выпадающий список срока (полгода / год), общая шкала «проинвентаризировано
  за период: X из Y мест», шкала в строке, красный счётчик «Просрочено или ни разу не проверялось», флажок
  «Показывать только невыполненные».
  Знаменатель — все конечные места, кроме удалённых и мест вида «Рабочее место»; «выполнено» — дата последней
  инвентаризации не старше выбранного срока.
- **Не найдено при инвентаризации** — отчёт о пропавших позициях, с регистром сведений `ПодтвержденныеПотери`
  (подтверждение потерь).
- Вся логика — в общем модуле `ИнвДатыСервер`.

Установка и сборка `.cfe` — как в [`tools/build_extension.bat`](../tools/build_extension.bat) (имя расширения `InventoryDates`).
