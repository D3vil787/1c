# 1С: расширения для «Управление IT-отделом» (Softonit 3.1)

Набор расширений конфигурации (формат выгрузки в XML) для «Управление IT-отделом 8», ред. 3.1 ПРОФ.
Проверено на платформе 8.3.27 (Softonit 3.1.23.4).

| Каталог | Что это |
|---|---|
| [`WarehouseTablet/`](WarehouseTablet) | Веб-страница для планшета на складе: перемещение, инвентаризация и добавление по штрихкоду/QR, печать этикеток на Zebra (HTTP-сервис). |
| [`InventoryDates/`](InventoryDates) | Отчёты по инвентаризациям: «Инвентаризации по местам хранения» (сроки, шкала выполнения) и «Не найдено при инвентаризации». |
| [`MinStockNotify/`](MinStockNotify) | Уведомления (Telegram/почта) о достижении минимального остатка. |
| [`tools/`](tools) | Скрипты сборки/проверки через пакетный режим конфигуратора и тест по COM. |
| [`docs/`](docs) | Заметки: комплекты в инвентаризации, рабочий процесс, грабли. |

## Как это собирается

Расширения не правятся в конфигураторе, а хранятся как исходники и грузятся командой
`/LoadConfigFromFiles … -Extension <Имя>`. Готовый `.cfe` получается выгрузкой `/DumpCfg`
(см. [`tools/build_extension.bat`](tools/build_extension.bat)). Все изменения сначала проверяются на копии базы
(файловая тестовая база + проверка модулей + вызов тестовых функций по COM).

Бинарные `.cfe` в репозиторий не кладутся: в собранных расширениях зашиты локальные настройки
(адреса принтеров, получатели почты). Правьте их под себя перед сборкой — места указаны в README каждого расширения.

## Лицензия

Не указана. Страница планшета использует библиотеку `html5-qrcode` (Apache-2.0), копия в `WarehouseTablet/vendor/`.
