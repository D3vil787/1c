# WarehouseTablet — склад: планшет

Расширение «Склад: планшет». Публикует HTTP-сервис `СкладПланшет` со страницей для планшета
(`/hs/sklad/page`) и API (`/hs/sklad/api/{Действие}`). Страница целиком лежит внутри модуля HTTP-сервиса
(одна строка-шаблон), поэтому никаких файлов на веб-сервер класть не нужно.

## Что умеет страница

- **Перемещение.** Сканируешь штрихкод / серийный № / инвентарный № карточки, выбираешь место — создаётся и
  проводится документ «Перемещение». Предметы, входящие в комплект, из страницы не перемещаются (только через 1С).
- **Инвентаризация.** Выбор места, переключатель «с подчинёнными», сканирование; результат сохраняется документом
  «Инвентаризация» **без проведения**. Недостающие можно отправить на место «Потеряшки». Комплекты — см. [docs/kits.md](../docs/kits.md).
  Незавершённая инвентаризация хранится в `localStorage` браузера.
- **Добавление.** Поиск номенклатуры по словам в наименовании, оформление поступления, печать этикетки.
- **Этикетки.** ZPL (203 dpi, 344×200): штрихкод либо QR (7,9 мм, QR слева в отрезаемом квадрате, текст справа).
  Печать — копированием ZPL на принтер, открытый общим доступом Windows (`\\сервер\принтер`).
- **Камера.** Живое сканирование через `html5-qrcode` требует HTTPS (или localhost). На обычном HTTP используется режим «Снимок».
- **Диагностика.** После загрузки списка в строке статуса стоит метка версии страницы (`· vNN`) — по ней видно,
  применилась ли новая версия на сервере. Адрес `…/page#diag=ЧастьИмениМеста` включает панель с данными таблицы учёта и регистра «Комплектация».

## Исходники и сборка

```
src/Module.bsl      общий модуль СкладПланшетСервер (вся серверная логика)
src/page.html       страница планшета
src/TestModule.bsl  общий модуль СкладПланшетТест (только в тестовой сборке)
vendor/             html5-qrcode (Apache-2.0)
gen.py              генератор XML-выгрузки расширения
```

`gen.py` берёт шаблоны `Configuration.xml`, языка и общего модуля из соседнего каталога `MinStockNotify/`:

```
python3 WarehouseTablet/gen.py out/ext_ws          # боевая сборка
TEST=1 python3 WarehouseTablet/gen.py out/ext_wst   # + модуль СкладПланшетТест
```

Перед сборкой замените в `src/Module.bsl` (функция `СписокПринтеров`, блок между `ПРИНТЕРЫ-НАЧАЛО` и `ПРИНТЕРЫ-КОНЕЦ`)
примеры принтеров на свои: `Название=\\сервер\принтер`, по одному в строке.

Дальше — `tools/build_extension.bat` (загрузка, проверка модулей, выгрузка `.cfe`).
Роль `СкладПланшет` выдаётся пользователю, под которым ходит сервис.

## Публикация и обновление

HTTP-сервис публикуется стандартно (веб-публикация с HTTP-сервисами). После установки новой версии расширения:

- **IIS**: перезапустить пул приложений сайта (Recycle). Без этого веб-расширение продолжает отвечать старой версией.
- Клиент-серверная база: при необходимости завершить сеансы базы в консоли кластера.
- Открыть страницу в режиме инкогнито и проверить метку версии в строке статуса.
- Незавершённую инвентаризацию на планшетах перед обновлением довести до конца или очистить: ключи строк могут измениться.

## Тесты

В тестовой сборке есть экспортные функции модуля `СкладПланшетТест` (скан, ЗПЛ, инвентаризация, комплекты…).
Вызываются по COM из 32-разрядного PowerShell — см. [`tools/com_call.ps1`](../tools/com_call.ps1).
Страница проверялась на мок-API через Playwright (Chromium).
